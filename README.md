# taptime

Tap filesystem time paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/taptime/

## Install / run

```bash
git clone https://github.com/theworker02/taptime.git
cd taptime
node src/cli.js
node --test
```
